# Portfolio-Academico-Sistemas



🎓 Portfolio Académico: Trabajos Prácticos y Proyectos de Sistemas

Autor: Diego Paparo | Estudiante de Análisis de Sistemas (ISSD)



¡Bienvenido a mi repositorio académico! Este espacio está dedicado a documentar y archivar los trabajos prácticos, modelados y proyectos integradores desarrollados a lo largo de mi formación en la carrera de Análisis de Sistemas en el Instituto Superior Santo Domingo (ISSD).



📂 Estructura del Repositorio

01-Modelado-UML/



Diagramas de Casos de Uso, Clases, Diagramas de Estado y Componentes orientados al diseño de software robusto.



Modelado de procesos de negocio y especificación de requerimientos funcionales.



02-Casos-de-Prueba-QA/



Diseño de casos de prueba funcionales (caminos positivos y negativos).



Estructuración de tabulados de prueba para asegurar la calidad y fiabilidad de las salidas del sistema.



03-Proyectos-Integradores/



Documentación funcional, especificaciones de arquitectura y entregas correspondientes a las materias de la carrera (como Sistemas de Información).



🛠️ Competencias Aplicadas

Ingeniería de Requerimientos: Levantamiento, análisis y modelado de sistemas transaccionales utilizando el Proceso Unificado (PUD) y UML.



Gestión y Metodologías Ágiles: Planificación de proyectos, desglose de épicas, historias de usuario y criterios de aceptación.



Aseguramiento de Calidad (QA): Validación de flujos operativos y diseño sistemático de pruebas de software.
